### Description

Repple Coach is where personal trainers run their coaching: programs, clients, sessions and payments.

WHO NEEDS YOU TODAY
• Today's sessions, and a Needs Attention inbox you can filter by replies, check-ins, programs and payments.
• Every flag gives its reason: overdue check-in, unread message, a program ending, an unpaid invoice.

BUILD PROGRAMS FAST
• A program builder with a searchable exercise library (pictures, muscle groups and synonyms), supersets, set methods, rest and progression.
• Templates, multi-week blocks, and assigning one program to many clients.

RUN YOUR BOOK
• Schedule, availability and bookings, with reminders.
• Session packs, invoices and payments.
• Messages, weekly check-ins, progress photos and body scans for every client.

Your clients use the free Repple app. You invite them with a code or a link.

### What's new (1.3.0)

• An Exercise Library sheet in the builder, with muscle-group filters.
• Fixes, and a lint check that catches a class of crash before release.
